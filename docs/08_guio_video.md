## Parte 3. Guion del vídeo


### 

El vídeo ha de distingir clarament: 
• Problema detectat: què succeeix i a qui afecta. 
• Solució proposada: com funcionaria l’aplicació. 
• Benefici esperat: què podria millorar. 
• Mesura del resultat: com comprovaríeu si funciona. 
• Suport necessari: què necessitaríeu per posar-la a prova.


###  Estructura del vídeo

**Duración prevista:** entre 3 y 5 minutos.

| Tiempo aproximado | Contenido | Participante | Recursos visuales |
|---|---|---|---|
| 0:00 - 0:30 | Presentación del problema | | |
| 0:30 - 1:15 | Personas afectadas, causas y consecuencias | | |
| 1:15 - 2:30 | Aplicación propuesta y funcionalidades principales | | |
| 2:30 - 3:15 | ODS relacionados y beneficios esperados | | |
| 3:15 - 4:00 | Riesgos y limitaciones de la propuesta | | |
| 4:00 - 4:30 | Indicadores para comprobar los resultados | | |
| 4:30 - 5:00 | Conclusión y propuesta de apoyo o prueba piloto | | |
